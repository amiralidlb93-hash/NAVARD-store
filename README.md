# NAVARD

یک صفحه‌ی تک‌صفحه‌ای برای برند پیراهن NAVARD. یک پیراهن در مرکز صفحه است و یک نور نرم دنبال موس می‌آید و داخل آن پارچه‌ی خام (toile) دیده می‌شود.

## لایو دمو

https://YOUR-USERNAME.github.io/navard/

## اجرا روی سیستم لوکال

```
python3 -m http.server 8000
```

http://localhost:8000

## ویژگی‌ها

- نور دنبال‌کننده روی عکس
- شبکه‌ی ظریف متحرک
- کشوهای ATELIER، LINES و NOTES
- سبد خرید با شمارنده، toast و Checkout
- ریسپانسیو، با عکس ثابت در موبایل
- پشتیبانی از reduced motion

## فایل‌ها

- `index.html`
- `styles.css`
- `script.js`

## طراحی

- رنگ‌ها: paper `#F4F2ED`، ink `#141310`، chalk `#C9C5BC`، ash `#8C877D`، grid `#A39E93`
- فونت‌ها: Archivo و Onest
- بدون فریم‌ورک و بدون کتابخانه‌ی انیمیشن
